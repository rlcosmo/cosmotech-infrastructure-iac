# Autorização de merges do Lab V2

Em 07/11/2026, o proprietário autorizou aprovação/merge automático de PRs atuais e futuros do Lab V2 após CI aprovado, ausência de conflitos e verificações de segurança. Não solicitar novamente aprovação do proprietário para essas ações já autorizadas.

Usar o merge normal do GitHub com SHA esperado do head verificado. Não remover proteções, descartar review obrigatório, usar bypass administrativo ou apresentar auto-review como aprovação humana independente. Caso o GitHub exija outro aprovador obrigatório, registrar o bloqueio sem contorná-lo.

A autorização de merge não concede permissões IAM inexistentes, não substitui GMUD/aprovação de deploy exigida pelo pipeline e não autoriza planos com alterações destrutivas ou custos recorrentes relevantes sem teto. Merge, CI e plan sem refresh não comprovam apply, publicação de portal ou instalação de dashboards. Preservar recibos do GitHub/CI e evidência real de implantação.
